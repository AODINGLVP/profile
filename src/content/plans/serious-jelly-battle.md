# 一、游戏概述

《Serious Jelly Battle》是一款本地单人 3D 俯视角布阵自动战斗游戏。玩家需要在战斗开始前选择并部署果冻单位，利用单位之间的能力组合应对不同敌人和战场条件。

战斗开始后，单位会自动寻路、索敌和执行攻击。玩家的核心决策集中在战前编队、站位、能力搭配，以及战斗过程中的有限干预。

# 二、核心玩法循环

1. 进入关卡并查看敌方阵容与战场地形。
2. 消耗金币选择单位，安排单位的部署位置。
3. 开始战斗，观察单位自主寻路、索敌与释放能力。
4. 根据战斗结果获得结算奖励，解锁下一场战斗或调整阵容。

# 三、战斗系统

战斗系统使用 Unreal Engine Gameplay Ability System 组织属性、技能和战斗事件。不同单位通过 Ability、AttributeSet 与 GameplayTag 组合出差异化的攻击、治疗、防御和控制能力。

当前设计中的能力方向包括：

- 近战攻击、远程攻击与范围伤害
- 护盾、治疗和受击减伤
- 召唤、分裂与旋风等特殊能力
- 魅惑、元素附加和其他状态效果

# 四、单位与 AI

单位使用 Behavior Tree 与 C++ 行为后备路径完成决策，并结合 NavMesh、动态寻路和 3D 地形高度处理，使单位能够在真实战场地形上移动、索敌和交战。

AI 设计重点是让不同单位在目标选择、移动距离、攻击范围和技能释放时机上形成清晰差异，同时保证自动战斗过程容易观察和理解。
